# 质量门禁检查清单

合并到 `main` 之前，**所有**门禁必须逐项检查通过。无一例外。

## 门禁 1：需求完整性
**负责人**：Orchestrator

- [ ] 本轮所有任务在 task-board.md 中标记为 Done
- [ ] 用户验收标准已达成
- [ ] 无范围蔓延 — 仅实现了已规划的任务
- [ ] 发现的后续工作已记录为新任务（而非阻塞当前合并）

## 门禁 2：架构设计 + 代码审查
**负责人**：Architect（步骤 2 设计）+ Reviewer（步骤 4 审查）

- [ ] 架构设计已输出实现约束清单（步骤 2）
- [ ] 代码审查已通过（步骤 4 Reviewer APPROVED）
- [ ] 层边界得到遵守（pages → services → utils）
- [ ] 无循环依赖
- [ ] 业务逻辑在正确层级
- [ ] 无已有功能的重复实现
- [ ] 新增模块/实体已在 architecture.md 和 data-model.md 中记录
- [ ] API 契约（云函数）已在 api-contract.md 中记录
- [ ] 重要设计选择已添加架构决策记录

## 门禁 3：测试结果
**负责人**：Tester

- [ ] 所有已计划的测试用例通过
- [ ] 回归测试通过（此前正常的功能未被破坏）
- [ ] 边界情况已覆盖
- [ ] 异常状态已处理（网络故障、无效输入、鉴权失败）
- [ ] 微信开发者工具验证已完成（最低要求：编译成功、页面可渲染）
- [ ] 所有 P0 和 P1 bug 已修复
- [ ] P2 bug 已记录并创建后续任务
- [ ] **测试包含实际运行时验证，非仅静态代码分析**
- [ ] **最终测试报告为 PASS 或 PASS WITH WARNINGS（不存在 FAIL 或 BLOCKED）**
- [ ] **如有迭代，上一轮所有 FAIL 用例已在本轮修复**

## 门禁 4：文档同步
**负责人**：Orchestrator

- [ ] feature-list.md 反映当前状态
- [ ] task-board.md 已更新
- [ ] changelog.md 有本轮变更条目
- [ ] cycle-log.md 已更新（本轮所有 agent 输出文件已索引）
- [ ] agent-outputs/ 目录下 6 个步骤的输出文件均已就位
- [ ] 如有项目级别变更，README.md 已更新
- [ ] 如设计变更，architecture.md 已更新
- [ ] 如 schema 变更，data-model.md 已更新
- [ ] 如 API 变更，api-contract.md 已更新
- [ ] test-plan.md 已更新新增的测试用例

## 门禁 5：Git 状态
**负责人**：Orchestrator

- [ ] `git status` 显示工作区干净（无与变更无关的未跟踪或修改文件）
- [ ] `git diff main...feature-branch` 仅显示预期变更
- [ ] 无调试代码、console.log 残留、注释掉的代码
- [ ] 无 `.env`、凭证、或隐私配置文件（project.private.config.json 已在 .gitignore 中）
- [ ] 提交信息遵循格式：`type: description`

## 门禁 6：隐私与数据安全
**负责人**：Architect + Tester

- [ ] 未向其他团队成员暴露原始体重值（除非主动开启共享）
- [ ] 团队视图仅展示进度百分比、趋势、或打卡状态
- [ ] 云数据库权限规则受限（仅写自身数据、读团队聚合数据）
- [ ] 云函数写入体重记录前验证所有权
- [ ] 分享链接/分享卡片参数中不含体重数据
- [ ] 日志和控制台输出中无敏感数据
- [ ] 适当位置已应用数据脱敏
- [ ] 管理员无法读取他人原始体重值（无明确授权时）

## 门禁 7：无回归
**负责人**：Tester

- [ ] 此前正常的功能仍可正常工作
- [ ] 微信开发者工具控制台无新增错误
- [ ] 无性能退化（应用启动、页面导航、数据加载）
- [ ] 已有云函数仍可部署运行

## 门禁 8：反过度设计
**负责人**：Architect

- [ ] 无仅服务单一用例的抽象（三法则）
- [ ] 无"以后可能需要"的推测性设计
- [ ] 无在简单问题上使用复杂模式（如为单事件处理使用 pub/sub）
- [ ] 适合 4 人团队应用 — 如果看起来像企业级 SaaS，就是错误的

## 门禁 9：异常处理
**负责人**：Tester

- [ ] 网络故障显示用户友好提示（非崩溃）
- [ ] 无效用户输入显示校验错误（非崩溃）
- [ ] 鉴权失败重定向到登录页（非空白页）
- [ ] 空状态已处理（如"暂无体重记录"而非空白屏幕）
- [ ] 云函数异常被捕获并返回结构化错误响应

## 门禁 10：小程序兼容性
**负责人**：Tester

- [ ] 微信开发者工具中应用编译无错误
- [ ] 所有页面在 iPhone 6/7/8 屏幕尺寸（375×667）下渲染正常
- [ ] 所有页面在 iPhone X/11/12 屏幕尺寸（375×812）下渲染正常
- [ ] 包大小在限制之内（在开发者工具 → 详情 → 代码依赖分析中查看）
- [ ] 分包配置正确（如使用分包）
- [ ] 未使用不支持的 Web API（window、document、localStorage 等）
- [ ] 所有 wx API 调用都有错误回调（不只有成功回调）

## 门禁 11：技能加载
**负责人**：Orchestrator

- [ ] 每个步骤开始前已通过 Skill 工具加载对应强制技能
- [ ] 被调度的 agent 在其提示词中包含技能加载指令
- [ ] agent 输出文件中可见加载技能的痕迹

## 门禁 12：时间戳准确性
**负责人**：Orchestrator

- [ ] cycle-log.md 中所有时间通过 `git log` 或 `date` 命令获取
- [ ] 无编造或估算的时间戳
- [ ] agent 输出文件中的时间与实际提交时间一致

## 最终决策

所有门禁通过 → **批准合并**
任一门禁未通过 → **拒绝合并**，需注明具体原因和负责人
