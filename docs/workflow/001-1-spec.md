# 周期 001 — 修复体重记录时间和布局 Bug

**类型**：fix | **结果**：进行中 | **分支**：`fix/weight-time-layout` | **迭代**：1

## 问题描述

1. **时间格式错误**：最近记录、记录历史中的时间显示为 ISO 原值（如 `2026-05-18T10:30:00.000Z`），时分秒全是 0，格式不符合 `YYYY-MM-DD HH:mm`
2. **布局错乱**：统计卡片和记录历史列表中部分组件超出屏幕

## 影响范围

- 页面：`miniprogram/pages/weight/index`
- 统计卡片（最近记录区域）
- 记录历史列表（所有记录项）
- 工具函数：`miniprogram/utils/date.js`

## 验收标准

1. 时间显示为 `YYYY-MM-DD HH:mm` 格式（如 `2026-05-18 10:30`）
2. 记录列表无组件超出屏幕
3. 统计卡片布局正常
4. `npm test` 全部通过

## 范围边界

**不做**：
- 不修改云函数（问题出在前端格式化）
- 不修改服务层逻辑
- 不修改数据模型

## 根因分析

- 云函数返回的 `recordedAt` 是 ISO 8601 格式（如 `2026-05-18T10:30:00.000Z`），前端 `loadRecords()` 直接将原值赋给 `records`，WXML 中 `{{item.recordedAt}}` 直接显示原值，缺少 `formatDateTime()` 格式化函数
- WXSS 缺少 `overflow`、`box-sizing` 等约束，导致 flex 子项溢出

## 修复方案

### 1. 新增 `formatDateTime()` 到 `utils/date.js`

```javascript
function formatDateTime(date) {
  if (!date) return '';
  const d = new Date(date);
  if (isNaN(d.getTime())) return '';
  const year = d.getFullYear();
  const month = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  const hour = String(d.getHours()).padStart(2, '0');
  const minute = String(d.getMinutes()).padStart(2, '0');
  return `${year}-${month}-${day} ${hour}:${minute}`;
}
```

### 2. 修改 `weight/index.js` — `loadRecords()` 中追加格式化

```javascript
const recordsFormatted = records.map(r => ({
  ...r,
  _formattedWeight: formatWeight(r.weight, r.unit),
  _formattedDate: formatDateTime(r.recordedAt)  // 新增
}));
```

### 3. 修改 `weight/index.wxml` — 时间显示改用 `_formattedDate`

- 统计卡片 `latestWeight.recordedAt` → `latestWeight._formattedDate`
- 记录历史 `item.recordedAt` → `item._formattedDate`

### 4. 修改 `weight/index.wxss` — 布局约束

| 选择器 | 新增 |
|--------|------|
| `.card` | `overflow: hidden; box-sizing: border-box;` |
| `.record-item` | `overflow: hidden; word-break: break-all; box-sizing: border-box;` |
| `.record-info` | `min-width: 0; overflow: hidden;` |
| `.record-actions` | `flex-shrink: 0; max-width: 180rpx; flex-wrap: wrap;` |
| `.flex-between` | `box-sizing: border-box;` |
