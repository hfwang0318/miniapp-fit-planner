# 周期 003 — 修复 dashboard 及图表时间格式

**日期**：2026-05-19
**类型**：fix
**推荐分支**：`fix/dashboard-date-format`

## 问题描述

Dashboard 页面的"最近记录"列表直接输出云函数返回的 `recordedAt` ISO 8601 原始字符串（如 `2025-05-18T16:00:00.000Z`），对用户极不友好。同时图表组件（weight-chart）的 X 轴标签使用 `substring(5)` 简单截取，会显示 `05-18T16:00:00.000Z` 等多余内容。

项目已有 `utils/date.js` 工具库（含 `formatDateTime`、`formatDateShort` 等函数），weight 页面已正确使用，但 dashboard 和图表组件未引入。

## 验收标准

1. Dashboard 最近记录列表日期显示为 `YYYY-MM-DD HH:mm` 格式（如 `2025-05-18 16:00`），与 weight 页面一致
2. 图表 X 轴标签显示为 `MM-DD` 格式（如 `05-18`），无多余字符
3. 空/无效日期不崩溃，显示空字符串
4. 现有测试全部通过

## 范围边界

- **做**：dashboard 页面日期格式化、图表 X 轴日期格式化
- **不做**：云函数返回格式不变（仍返回 ISO 字符串）、其他页面的日期逻辑

## 涉及文件

| 文件 | 变更 |
|------|------|
| `miniprogram/pages/dashboard/index.js` | 引入 `formatDateTime`，为 `recentEntries` 添加 `_formattedDate` 字段 |
| `miniprogram/pages/dashboard/index.wxml` | `item.recordedAt` → `item._formattedDate` |
| `miniprogram/components/weight-chart/index.js` | 引入 `formatDateShort`（或直接用 `formatDate`），X 轴标签改用格式化函数 |
