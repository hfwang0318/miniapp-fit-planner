# 需求规格说明书 — 侧边栏组件

## 基本信息

- **周期**：cycle-002
- **分支**：`feature/sidebar`
- **类型**：feature

## 需求描述

增加一个侧边栏，可以全局弹出，显示用户基本信息并提供退出登录功能。

## 验收标准

1. 侧边栏可从 Dashboard 导航栏右侧的菜单按钮触发弹出
2. 侧边栏从右侧滑入（带动画）
3. 侧边栏显示用户头像、昵称、加入日期
4. 点击遮罩层可关闭侧边栏
5. 退出登录按钮需二次确认，确认后清除会话并跳转 login 页面
6. 所有页面（dashboard、weight）均可使用侧边栏

## 范围边界

**不做什么**：
- 不实现用户信息编辑功能
- 不实现隐私设置页面
- 不添加新的云函数
- 不添加新的服务层方法

## 用户信息显示

可用字段（来自 `app.globalData.user`）：
- `openid` — 用户唯一标识
- `nickName` — 微信昵称（无则显示"用户"）
- `avatarUrl` — 微信头像（无则显示默认头像）
- `createdAt` — 账户创建时间（格式：YYYY年MM月）

## 退出登录流程

```
用户点击"退出登录"
    ↓
wx.showModal 确认框（标题："确认退出"，内容："确定要退出当前账号吗？"）
    ↓
用户确认 → app.clearUserSession()（已有方法）
    ↓
wx.redirectTo({ url: '/pages/login/index' })
```
