# 周期 008 — 登录昵称设置弹窗

**日期**：2026-05-19
**类型**：feature
**推荐分支**：`feature/login-nickname-modal`

## 问题描述

当前登录流程为纯"微信一键登录"：用户点击按钮后直接进入 dashboard，`User` 文档的 `nickName` 被设为默认的 "WeChat User"，`avatarUrl` 为空。用户没有任何机会在首次使用时设置自己的昵称和头像。

## 验收标准

1. 新用户登录成功后、进入 dashboard 前，显示强制性的昵称设置弹窗（不可关闭）
2. 弹窗提供两个选项：
   - **"使用微信昵称"按钮**：获取微信昵称 + 头像，同步更新到 User 文档
   - **自定义输入**：输入框 + 确认按钮，输入校验：非空、最多 30 字符、允许 emoji
3. 自定义输入时可勾选"同时设置微信头像"（需额外调用 `wx.getUserProfile`）
4. 用户确认后调用云函数更新 User 文档的 `nickName` 和 `avatarUrl`，然后进入 dashboard
5. 老用户（已设置昵称）直接进入 dashboard，不弹出
6. 现有测试全部通过

## 范围边界

- **做**：login 页面修改、auth 云函数增加 update 接口、服务层 authService 增加 update 方法、相关 UI 组件
- **不做**：dashboard 页面修改、个人资料页、头像裁剪功能

## 用户流程

```
用户点击"微信一键登录"
    ↓
authService.login() → 云函数创建/获取 User 文档
    ↓
返回 { openid, isNewUser, nickName? }
    ↓
如果 isNewUser && nickName === 默认值
    ↓
显示昵称设置弹窗（阻塞 dashboard 跳转）
    ↓
用户选择"使用微信昵称" 或 "自定义输入+确认"
    ↓
调用 authService.updateProfile({ nickName, avatarUrl? })
    ↓
更新 User 文档
    ↓
进入 dashboard
```
